# 前端界面层级优化

视觉方向：保留绿色作为操作强调色，使用中性底色与清晰文字，以留白和分隔线形成工作区层级，移除重复卡片与装饰渐变。

内容组织：页面标题与主要动作 → 分类/筛选 → 主列表或表单 → 次要说明。列表使用连续行；编辑器作为独立侧栏；设置使用章节；数据使用批次列表与指标条。

交互方向：按钮、行选择与导航使用短促的背景/边框过渡；保留可见焦点，尊重减少动画设置。去掉悬浮位移与重复入场动画，保持操作稳定。

范围：外壳、导入、阅读/听力/写作题库、设置、数据统计。保留考试纸面与真实学生渲染器现有视觉契约，保留用户原有七处未提交改动。

验证：浏览器显式开发 fallback 的产品界面、真实组件测试、TypeScript 检查；不将这些证据等同于原生 Tauri/NAS 端到端验证。运行中的 Tauri 开发服务保持运行。
