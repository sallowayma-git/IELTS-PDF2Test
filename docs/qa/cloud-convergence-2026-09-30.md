# 云端主链收敛实施与验收记录（2026-09-30）

本轮代码已实现候选先接收、按依赖单元部分采用、来源校核和最后发布检查。当前正式稿保留版本事务和人工修改保护；缺答案与最终质量不就绪不再拒收整份候选。

## 实施范围

- 本地误识别的多余题号不再阻止云端候选；异常单元交校核，其他单元可先进入编辑器。
- 题型、呈现、作答数量、分组、原文、选项、答案和听力分段参与对账；来源元数据、空白和等价默认约束不制造人工选择。
- 批量四类裁定，默认一次补证；来源支持的整组采用或编辑完成后不额外确认。非法回复有一次受约束修复，失败、取消、超时保留当前稿。
- 以原文件哈希稳定抽样，初始相似度阈值 80%。低于阈值扩大核验，通过也不声明全文逐句正确。题号、选项标签、答案位与作答数量全量比较。
- 题目区域展示蓝色本地与绿色云端完整只读题组。选择前保存，使用当前版本事务写入，重复提交幂等；无候选的问题提供原文件与定位修复入口。
- 独立答案页冲突在校核前进入同轮材料；待选择差异与答案页冲突使用同一最终发布判据。
- 阅读 V1 兼容编译不再阻断；旧稿加载重算过期质量报告，现役听力 ListeningExamSourceV1 保留。
- 候选、校核和答案页共用整轮撤销归属，保留最近有效写入；失败空运行不提前删除上一轮。后续人工修改保留并报告跳过项。
- 默认请求日志仅保留摘要；完整请求响应需 IELTS_LLM_DIAGNOSTICS=1。机器写入日志保存摘要哈希和必要路径差异；已结束旧候选按有效撤销与运行状态清理。学生包继续剥离编辑信息。

实际尝试：npm run e2e:tauri 明确退出，现有驱动要求 Windows WebView2，当前宿主是 macOS；Computer Use 的原生服务两次返回 Sky Computer Use service startup request failed。不能以浏览器模拟后端或命令测试代替这项验收。
