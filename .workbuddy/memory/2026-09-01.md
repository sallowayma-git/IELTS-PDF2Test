## 环境问题（重要）

- 本机 git 走 `http://127.0.0.1:7897` 代理时，`git fetch` / `unshallow` 频繁报 `RPC failed; curl 56 schannel: server closed abruptly` + `early EOF / invalid index-pack output`。
- 绕过代理直连 GitHub 成功率高很多。已在本仓库设置 `git config --local http.proxy ""` 和 `https.proxy ""`。
- 另有一个坑：fetch 失败会把 `.git/refs/remotes/origin/` 整个目录连同引用一起清掉（reflog 里却有记录），需要 `mkdir -p .git/refs/remotes/origin` 后手动写入 sha 恢复。
