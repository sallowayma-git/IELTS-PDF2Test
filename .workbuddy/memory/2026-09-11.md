### 已关闭

1. **`load_current_authoring` shadow 优先级**（`authoring_v2_commands.rs`）：旧逻辑在 `revision == 0` 时先读磁盘 shadow，即使 DB 已有权威稿；DB 编辑后 shadow 陈旧 → 该路径读到改前内容。改为 revision → DB canonical DS → shadow（shadow 仅服务未迁移 job）。新增回归测试 `product_chain::legacy_authoring_session_reads_the_db_draft_not_the_stale_shadow`，断言旧会话返回 DB 标题而非陈旧 shadow 标题。

### M4 / P4-T01 首个增量：统一物理提取入口（DOCX 对齐）

- 缺口：`auto_pipeline.rs` 只在 `file_type == "pdf"` 时物化物理 DocumentIRV2；手工路径 `authoring_commands.rs::parse_document` 已支持 `pdf | docx`。于是**自动导入的 DOCX 完全没有物理层** → 无法产出 authoring V2 会话 → 永远到不了 ready/发布。原测试注释自己写明了「the physical DocumentIRV2 shadow is only written for PDFs」。
